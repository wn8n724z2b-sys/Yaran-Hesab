# حسابداری آسان v3.0 — Minimal Pro UI

نسخه رایگان Windows Native برای Windows 10/11 64-bit.

## تغییرات اصلی v3
- بازطراحی کامل رابط بر اساس ساختار داشبورد حرفه‌ای و مینیمال؛ بدون افزودن ماژول‌های ساختگی.
- Sidebar راست‌چین با بخش‌های واقعی سیستم: داشبورد، فروش، کالاها، مشتریان/شرکت‌ها، دسته‌ها، هزینه‌ها، گزارش‌ها، انبارداری، داده‌ها/پشتیبانی و تنظیمات.
- Dashboard جدید با 5 KPI واقعی، نمودار، فروش‌های اخیر و دسترسی سریع.
- صفحه‌بندی 10/20/50 برای کالاها، مشتریان، شرکت‌ها، هزینه‌ها، انبار و فاکتورها.
- فاکتورهای روزمره محدود به تعداد انتخاب‌شده و آرشیو کامل جداگانه با جستجو، تاریخ و صفحه‌بندی.
- گزارش مالی با بازه‌های امروز، دیروز، 7 روز گذشته، ماه جاری، ماه قبل، دوره حسابی، همه اطلاعات و بازه سفارشی.
- نمودار گزارش شامل فروش، هزینه، قرض، پرداخت قرض مشتریان و سود خالص؛ هر سری قابل روشن/خاموش است.
- Expense Center مستقل. هزینه‌ها در state اصلی و جدول SQLite `expenses` ذخیره می‌شوند و در سود خالص و Cashflow استفاده می‌شوند.
- صفحه دسته‌ها برای جستجو، ویرایش، جابه‌جایی و حذف امن دسته‌ها.
- Scroll عمودی فقط روی صفحه فعال؛ جدول‌ها دیگر Wheel عمودی را قفل نمی‌کنند.
- اعداد رابط انگلیسی، واحد پول `؋` و فونت Vazirmatn Variable آفلاین.
- نسخه آموزشی 2 ماه و 10 روزه با کالا، دسته، مشتری، شرکت، خرید، فروش، قرض، هزینه و انبار.
- SQLite Native، Backup، Audit فاکتور، XPrinter و USB HID حفظ شده‌اند.

## Build
در GitHub Actions یا Windows:

```bash
npm install
npm run build
```

خروجی NSIS در مسیر Tauri bundle ایجاد می‌شود.
