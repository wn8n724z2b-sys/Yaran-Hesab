YARAN FINANCIAL SYSTEM — CLOUD BUILD GUIDE

You do NOT need Visual Studio, Rust or Node.js on your own PC for this method.
GitHub Actions builds the Windows installer on a cloud Windows machine.

ONE-TIME SETUP
1) Create/sign in to a GitHub account.
2) Create a new PRIVATE repository. Suggested name: yaran-financial-system
3) Upload the CONTENTS of this folder to the repository root.
   Important: upload the contents, not one extra parent folder.
4) Open the repository's Actions tab.
5) Choose: "Build Yaran for Windows"
6) Click: "Run workflow" -> "Run workflow"
7) Wait until the job shows a green check mark.
8) Open that successful run.
9) At the bottom, under Artifacts, download: Yaran-Windows-Installer
10) Extract the downloaded artifact. The NSIS Setup .exe will be inside.

AUTOMATIC BUILDS
Any future push to the main branch also starts a new Windows build automatically.

WHERE THE INSTALLER COMES FROM
src-tauri/target/release/bundle/nsis/*.exe

IMPORTANT
This is still the current Alpha codebase. Do not use it for live accounting until the
full production SQLite data model, backup/restore validation and direct XPrinter path
are finalized and tested.
