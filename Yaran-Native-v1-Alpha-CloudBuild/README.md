# حسابداری آسان — نسخه رایگان v1.2

نسخه دسکتاپ Local-first برای Windows 10/11 64-bit با SQLite Native، فروش، خرید، انبار، مشتری/شرکت، قرض، هزینه، گزارش، Backup، بارکدخوان USB HID و چاپ رسید حرارتی.

## تغییرات اصلی v1.2

- ساعات کاری هر روز از **اولین اجرای همان روز** محاسبه می‌شود و با باز/بسته شدن برنامه از صفر شروع نمی‌شود.
- نمودار «گردش نقدی ماه جاری» بازطراحی شده: ورودی نقدی، خروجی نقدی و خالص نقدی با مقیاس پویا و Tooltip روزانه.
- گزارش فاکتورهای فروش حرفه‌ای‌تر شده: جستجو، فیلتر نقدی/نسیه، آمار سریع و خروجی Excel-compatible CSV.
- دسته‌بندی‌ها قابل ساخت، تغییر نام، جابه‌جایی و حذف تأییدی هستند.
- منو، آیکن‌ها و هویت برنامه RTL شده‌اند؛ فونت از فونت‌های داخلی Windows استفاده می‌کند و نیاز به دانلود فونت ندارد.
- مشتری پیش‌فرض هر فاکتور «مشتری عمومی» است و انتخاب مشتری با جستجوی سریع انجام می‌شود.
- روش پرداخت هیچ پیش‌انتخابی ندارد و انتخاب «نقدی» یا «نسیه» قبل از ثبت الزامی است.
- جدول کالا برای بارکدهای بسیار بلند ثابت می‌ماند و بارکد با Ellipsis + Tooltip نمایش داده می‌شود.
- بارکدخوان USB HID بعد از دریافت اسکن سریع به‌عنوان فعال علامت می‌خورد؛ وضعیت بدون اسکن «شناسایی نشده/نامشخص» می‌ماند.
- هنگام بستن برنامه تأیید گرفته می‌شود و قبل از خروج یک Backup Native ایجاد می‌شود.
- Backup دستی Native به پوشه Downloads خروجی SQLite می‌دهد و فقط 12 Backup خودکار اخیر نگه داشته می‌شوند.
- Audit فاکتورها به سبک Recent Activities ساده شده و فهرست عمومی Audit به 2000 رویداد اخیر محدود می‌شود تا در استفاده بلندمدت سبک بماند.
- نمونه آموزشی 35 روزه اضافه شده که فروش، نسیه، خرید، هزینه، دریافت/پرداخت قرض، موجودی و کالاهای بسته‌ای را پوشش می‌دهد.
- انبار ارتقا یافته: وضعیت موجودی، ارزش انبار، ناموجود/کم‌موجود، جستجو، اصلاح موجودی، کاردکس و خریدهای اخیر.
- لینک «ساخته شده توسط © MNRAHIMI . Ltd» به Telegram سازنده متصل است.

## نکته CSV
CSV یک فایل جدولی استاندارد است که Excel آن را باز می‌کند. خروجی v1.2 با BOM UTF-8 ایجاد می‌شود تا متن دری/فارسی در Excel درست نمایش داده شود.

## سازگاری
هدف رسمی این نسخه **Windows 10 64-bit و Windows 11 64-bit** است. برنامه WebView2 را از طریق Installer مدیریت می‌کند. Windows 7/8 به‌عنوان سیستم پشتیبانی‌شده اعلام نمی‌شوند.

## Build
در Repository فعلی GitHub، Workflow موجود را نگه دارید و پوشه پروژه را Commit کنید. GitHub Actions فایل Setup ویندوز را می‌سازد.
