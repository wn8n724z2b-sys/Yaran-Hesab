# حسابداری آسان — نسخه رایگان v2.0

نسخه v2 یک بازسازی ساختاری رابط دسکتاپ است؛ تمرکز اصلی آن رفع مشکلات Scroll/Mouse Wheel، کاهش شلوغی بصری و بازطراحی گزارش گردش نقدی ماه جاری است. هسته SQLite، فروش، خرید، انبار، Backup، Audit، چاپ و بارکدخوان نسخه‌های قبلی حفظ شده‌اند.

## تغییرات کلیدی v2

- Shell دسکتاپ بازتنظیم شد: کل Window اسکرول نمی‌شود و فقط محتوای صفحه فعال Scroll عمودی دارد.
- `table-wrap` فقط Scroll افقی دارد و دیگر Wheel عمودی ماوس را در جدول‌ها گیر نمی‌اندازد؛ بنابراین پس از پایین رفتن، بالا رفتن با Wheel طبیعی است.
- Overscroll و رفتارهای شبیه Browser از Containerهای تو در تو حذف یا محدود شدند.
- UI در داشبورد، گزارش‌ها، فرم‌ها، تنظیمات و جدول‌ها مینیمال‌تر شد: فاصله‌ها کمتر، سایه‌ها حذف، Radiusها یکدست و کارت‌ها آرام‌تر شدند.
- نمودار «گردش نقدی ماه جاری» از نمودار شلوغ Bar+Line به یک منحنی خالص نقدینگی با Area ملایم تبدیل شد. ورود، خروج و خالص ماه به‌صورت سه عدد خلاصه بالای نمودار دیده می‌شوند و جزئیات روز با Hover قابل مشاهده است.
- فونت Vazirmatn Variable همچنان به‌صورت آفلاین داخل Build/Installer بسته‌بندی می‌شود.
- فلش Select استاندارد Windows است و فقط یک فلش نشان داده می‌شود.
- نسخه محصول و Installer به `2.0.0` ارتقا یافت.

## تست‌های انجام‌شده

- JavaScript syntax با Node بررسی شد.
- JSONهای Tauri/package/capability parse شدند.
- ID تکراری در HTML بررسی شد و موردی وجود ندارد.
- تعادل Blockهای CSS بررسی شد.
- مسیر Scroll اصلی بازبینی شد تا Nested horizontal tables، Wheel عمودی را مسدود نکنند.

## Build

در Repository فعلی GitHub، پوشه `Yaran-Native-v1-Alpha-CloudBuild` را با نسخه داخل این بسته جایگزین کنید و Commit بزنید. Workflow موجود Setup ویندوز را Build می‌کند.
