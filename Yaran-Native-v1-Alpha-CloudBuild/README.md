# حسابداری آسان 3.2 — نسخه رایگان پایدار

بازسازی نهایی رابط بر پایه هسته Native/SQLite.

## اصلاحات اصلی
- پروفایل مدیر با نام و عکس قابل تنظیم، بدون دکمه‌های اضافی کنار پروفایل.
- لوگوی ثابت برنامه از آیکن اصلی حسابداری آسان؛ لوگوی فروشگاه فقط در هویت فروشگاه و رسید استفاده می‌شود.
- هویت فروشگاه با پیش‌نمایش محدود و بدون شکستن Layout.
- حذف فروش سریع/کالاهای سریع از صفحه فروش.
- Backup خودکار با انتخاب 1 تا 6 بار در روز و پیش‌فرض 4 بار.
- حذف گزینه نمونه آموزشی از برنامه اصلی.
- صفحه‌بندی واقعی کالاها و فاکتورهای گزارش با 20 یا 50 ردیف.
- نمودارهای داشبورد و گزارش با SVG شفاف و خطوط صریح؛ بدون پس‌زمینه سیاه.
- Footer سازنده در مرکز سایدبار و لینک مستقیم Telegram.
- Vazirmatn Variable آفلاین همراه Installer.
