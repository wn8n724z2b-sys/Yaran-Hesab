# حسابداری آسان v3.0 — UI Reset

این نسخه یک بازطراحی کامل رابط کاربری است؛ هسته Native/SQLite و قابلیت‌های نسخه‌های قبلی حفظ شده‌اند، اما پوسته بصری از صفر یکپارچه شده است.

## اصول طراحی v3
- فروش، جریان اصلی برنامه است.
- یک Design System واحد برای همه صفحه‌ها.
- فقط یک Scroll عمودی در صفحه فعال.
- کارت کمتر، مرزبندی ظریف‌تر، فضای تنفس بیشتر.
- خوانایی استاندارد از فاصله عادی مانیتور؛ بدون ریزمتن‌های کاربردی.
- Vazirmatn Variable به صورت آفلاین همراه Installer.
- Light و Dark با ساختار یکسان.
- Dialogهای داخلی برنامه؛ بدون پیام‌های مرورگری.
- جدول‌های پایدار برای بارکدهای بلند.

## قابلیت‌های حفظ‌شده
فروش و بارکد، کالا و 15 بارکد، دسته‌ها، خرید بسته‌ای/دانه‌ای، میانگین موزون، انبار و کاردکس، مشتری و شرکت، قرض و پرداخت، هزینه، گزارش‌ها، دوره حسابی، ویرایش/حذف فاکتور با Audit، Backup/Restore، XPrinter، نسخه آموزشی، Dark/Light و SQLite Native.

## Build
از GitHub Actions موجود یا `npm run build` استفاده کنید.
