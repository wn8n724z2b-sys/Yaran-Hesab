# حسابداری آسان — نسخه رایگان v1.0

نرم‌افزار حسابداری و فروش محلی برای Windows 10/11 64-bit. این نسخه رایگان است و از SQLite Native، فروش، کالا، خرید، انبار، قرض، هزینه، گزارش، Backup، بارکدخوان USB HID و چاپ رسید حرارتی Windows پشتیبانی می‌کند.

## ارتقای داشبورد
نمودار «روند مالی روزانه» سه شاخص را به‌صورت پویا نمایش می‌دهد:
- فروش: خط آبی و ناحیه ملایم
- قرض‌ها / فروش نسیه: خط سرخ
- مفاد خالص: خط سبز

بازه نمودار بین 7 روز، 30 روز و ماه جاری قابل تغییر است. مقیاس نمودار بر اساس داده واقعی تغییر می‌کند و با پنهان‌کردن مبالغ، اعداد Tooltip و محور نیز مخفی می‌شوند.
