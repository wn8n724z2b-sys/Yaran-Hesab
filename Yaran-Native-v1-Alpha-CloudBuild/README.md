# حسابداری آسان v4.0 — Reference UI

این نسخه رابط کاربری را با قالب تاییدشده بازسازی می‌کند و تمام هسته و داده‌های قبلی را حفظ می‌کند.

- همان شناسه Tauri و مسیر دیتابیس قبلی حفظ شده است.
- SQLite، کالاها، فاکتورها، خریدها، اشخاص، انبار، گزارش‌ها، Backup، Audit، XPrinter و بارکدخوان بدون تغییر ساختاری باقی مانده‌اند.
- رابط جدید از یک فایل CSS واحد `dist/app-v4.css` استفاده می‌کند.
- آیکن‌ها Inline SVG هستند و کاملاً آفلاین کار می‌کنند.
- Dashboard، Sidebar، Topbar، کارت‌ها، نمودار، فروش‌های اخیر و دسترسی سریع بر اساس قالب تاییدشده بازطراحی شده‌اند.
- تم روشن و دارک هر دو حفظ شده‌اند.
