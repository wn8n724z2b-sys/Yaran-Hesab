# حسابداری آسان v2.2 — Sales Flow

نسخه رایگان دسکتاپ با تمرکز اصلی روی فروش سریع و رابط مینیمال.

## تغییرات اصلی
- صفحه فروش به صفحه آغازین برنامه تبدیل شد.
- بخش کالاهای سریع/پرفروش از صفحه فروش حذف شد.
- کارت‌ها و سطوح با پالت آرام و تیره/روشن الهام‌گرفته از Mini Appهای تلگرام بازطراحی شدند.
- نوار اسکن و جستجو بزرگ‌تر و واضح‌تر شد.
- پنل پرداخت ساده‌تر و فشرده‌تر شد.
- دکمه «برگشت آخرین قلم» به جریان فروش اضافه شد.
- انیمیشن‌ها کوتاه و کنترل‌شده ماندند.
- Vazirmatn آفلاین و تمام هسته SQLite/Backup/Audit نسخه 2.1 حفظ شده‌اند.
