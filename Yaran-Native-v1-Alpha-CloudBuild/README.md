# حسابداری آسان — نسخه رایگان 3.3

این نسخه روی پایدارسازی تجربه صندوق فروش و رفتار Desktop تمرکز دارد.

- تمام مبالغ نمایشی بدون اعشار
- ساعات کاری = مجموع زمان فعال بودن برنامه در همان روز؛ فاصله‌ای که برنامه بسته است محاسبه نمی‌شود
- ساعت سیستم داخل کارت شیشه‌ای کنار ساعات کاری
- انتخاب مشتری کاملاً داخلی، جستجوپذیر و هماهنگ با قالب برنامه
- منوهای Sidebar کمی Boldتر
- حذف گزینه برش خودکار
- اصلاح منوی سه‌نقطه عملیات، مخصوصاً هزینه‌ها
- شماره‌گذاری اقلام فاکتور و رسید چاپی
- بعد از بیش از 10 قلم، جدول فاکتور ارتفاع ثابت و Scroll داخلی دارد
